## 项目

### fast-gateway

Go 语言写的 API 网关，支持路由转发、服务发现、负载均衡、熔断降级。

- 语言：Go
- 谓词：Path / Method / Host / Header 等 12 种
- 过滤器：请求头 / 响应头 / 路径重写 / Body 修改等 38 种
- 服务发现：Nacos / Consul / Kubernetes
- 配置中心：Apollo / Nacos Config / 本地文件
- 可观测：Prometheus 指标 / OpenTelemetry 链路追踪
- 容错：熔断器 / 降级 / 限流

[源码](https://github.com/winlping-open/fast-gateway) · [用户手册](https://github.com/winlping-open/fast-gateway/blob/main/docs/user-manual.md)
